# reserve-bank-demo

This is my working build for a short-term LiteLLM/AI-gateway sprint interview. The point is to know the material cold, not to ship a product.

I'm building it on a fresh AWS t3.large (Ubuntu 24.04) with no GPU. Local model support is optional later; the main path is AWS Bedrock Claude via least-privilege IAM.

The living document is docs/gateway-security-architecture.md. It tracks what I can do and what I recommend, written as a control narrative.
